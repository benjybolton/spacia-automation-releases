# Spacia Test Runner – releases

Installers for the **Spacia Test Runner**, the desktop app that tests app.spacia.africa automatically.
This repository holds only the installers; the app checks it for new versions and offers to update
itself.

**Install:** open the latest release under **Releases** and download
`Spacia Test Runner Setup <version>.exe`, then run it. Windows may say the publisher is unknown (the
app isn't code-signed yet): choose **More info → Run anyway**.

The installer contains the test code only: no accounts, passwords or test results. Each tester enters
their own test accounts when the app first starts.
